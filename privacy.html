隐私政策

俄语翻译学习 · 生效日期：2026 年 9 月 5 日

本隐私政策说明「俄语翻译学习」（走遍俄罗斯，以下简称「本应用」）如何收集、使用和存储您的信息。本应用由个人开发者维护，坚持本地优先、最小收集：不放广告、不设跟踪。深度翻译通过作者提供的云端服务中转；未填接入码的新设备可免费试用 3 天（每天 25 次深度功能），试用结束需向作者购买接入码继续使用。您也可以选择注册邮箱账号（可选功能），用于收藏云同步与套餐管理。

一、我们收集哪些信息

  • 本地存储的数据（仅存于您的设备）：收藏的单词、学习设置（课本、目标等级、朗读速度等）、翻译与变位分析缓存。这些保存在您设备的浏览器本地存储中，不会上传。
  • 翻译内容：您在翻译、词典、变位分析、课堂翻译中输入或选择的文本，会被发送到翻译服务提供商进行处理，以返回翻译或分析结果。
  • 课堂语音：使用「课堂语音翻译」时，需要麦克风权限，用于实时识别课堂语音。识别由作者提供的云端服务（Cloudflare 语音识别）完成，音频片段会发送到云端用于转写。课堂的全程录音仅保存在您自己的设备上（IndexedDB/下载文件），本应用不会自动上传完整录音。
  • API Key：您在设置中填写的 API Key 仅保存在本地浏览器，用于向服务商发起请求，本应用不会收集或上传它。
  • 设备标识：使用深度功能时，应用会在您的设备上生成一串随机标识，并在云端记录该标识、网络 IP 地址与首次/最近使用时间，用于免费试用额度统计和防止刷取额度（如防止反复重置试用）。该标识随机生成、不关联您的真实身份；您注册账号时，设备与账号的关联也会被记录，仅用于防滥用。
  • 账号信息（可选）：您选择注册邮箱账号时，我们只保存您的邮箱地址、加盐哈希后的密码（不保存明文）以及您选择同步的收藏内容。不注册账号也可正常使用本应用。
  • 意见反馈：您主动提交的反馈内容和选填的联系方式会发送到作者的服务器，仅用于改进应用与回复您的问题，不用于其他用途。

二、信息去向

  • 翻译内容会发送给您配置的翻译服务商（默认 DeepSeek，部分场景回退到 MyMemory / LibreTranslate 等免费服务），由它们处理请求。请参阅各服务商的隐私政策了解其数据处理方式。
  • 本应用的本地代理服务（proxy.js）会记录请求日志，仅用于排查运行问题，日志中不包含您的 API Key。

三、我们不做什么

  • 注册账号为可选功能；我们不主动收集您的姓名、手机号等身份信息，仅在您选择注册时保存邮箱地址。
  • 不进行任何形式的广告、数据分析、用户画像或跨网站跟踪。
  • 不将您的数据出售、出租或用于本隐私政策之外的用途。

四、数据存储与删除

  • 本地数据可随时自行清除：在应用「更多 → 设置 → 数据管理」中清空收藏；或清除浏览器对该站点的存储数据（全部本地数据随之删除）。
  • 注册账号产生的云端数据（邮箱、哈希密码、收藏同步内容、设备登记记录）保存在作者的服务器中；如需删除账号及全部云端数据，可通过第七条的联系方式联系我们处理。

五、未成年人

本应用不面向未成年人定向提供服务，也不会有意收集未成年人信息。如您是家长并认为孩子向我们提供了个人信息，可联系我们删除。

六、政策更新

本政策可能随应用功能调整而更新，更新后会在本页面公布并标注新的生效日期。重大变化会通过应用内提示告知。
