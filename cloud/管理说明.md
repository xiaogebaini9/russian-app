# 云端服务管理说明

> 2026-09-02 部署完成。深度翻译已从"作者电脑"迁移到 Cloudflare 全球节点，
> 用户只需联网 + 接入码即可使用，作者电脑不再需要开机。
> **服务地址：https://aimisi.top**（国内、哈萨克斯坦均可直接访问）

## 架构

```
用户 App/APK → https://aimisi.top（Cloudflare Worker）→ DeepSeek API
                  ↑ 持有真 Key、校验接入码、扣次数、缓存
```

- 服务端代码：`cloud/worker.js`（与本地 `proxy.js` 接口完全一致）
- 接入码存储：Cloudflare KV（9 个旧码已于部署日迁移，用量记录一并保留）
- 静态页面：Worker 直接托管 `www/` 目录，手机浏览器打开 https://aimisi.top 即可当 PWA 用
- 域名：aimisi.top（阿里云注册），DNS 托管在 Cloudflare，绑定到 Worker

## 日常操作（都在本目录命令行）

前置：`cloud.json` 存了服务地址和管理令牌（已加 .gitignore，绝不能外传/上传）。

```bash
node gen-codes.js 8               # 生成 8 个码（每码每日 100 次，永久有效）
node gen-codes.js 8 --days 30     # 月卡：30 天后自动过期
node gen-codes.js 8 --total 3000  # 次数卡：总共可用 3000 次
node gen-codes.js 8 --name 客户A  # 加备注名
node gen-codes.js list            # 查看所有码、今日用量、有效期
node gen-codes.js del 4826159     # 停用某个码（立即生效）
node gen-codes.js key sk-xxx      # 更新服务端 DeepSeek Key（余额不足换key时用）
node gen-codes.js import          # 把本地 codes.json 一键同步到云端（码库丢失时恢复）
```

收费建议：月卡卖 `--days 30`（可再配 `--daily 200` 提高每日限额），次数卡卖 `--total N`。

## 修改服务端代码后重新部署

```bash
cd cloud
wrangler deploy
```

改 `index.html` 后：跑一次 `sync.bat`（同步 www/ 和 APK 资产），再 `cd cloud && wrangler deploy`
让云端托管的网页也更新，最后 push GitHub 出新 APK。

⚠️ **重要：不要随便运行 `wrangler dev` 调试！** 新版 wrangler 的本地调试会
**直连真实的云端 KV**（不是本地模拟），调试时的导入/改码会直接改掉线上数据。

⚠️ **码库数据一律通过 gen-codes.js 管理**（它走 Worker 的管理接口）。
实测发现：用 `wrangler kv key put` 命令行直接写入的数据，线上 Worker 可能读不到
（Cloudflare KV 一致性问题），但 Worker 自己写入的数据永远读得到。
所以恢复码库用：`node gen-codes.js import`（本地 codes.json 是完整备份）。

## 本地模式（语音识别专用）

Whisper 语音识别只能跑在作者电脑上：
1. 电脑上 `node proxy.js`（旧本地代理，不用动）
2. App 设置 → 服务器地址 填 `http://作者电脑IP:8765`
3. 清空该设置则回到云端模式

注意：本地 `proxy.js` 只认本地 `codes.json` 里的码。自己用本地模式时，
在设置里直接填你的 sk- Key（直通，不占接入码额度）。

## 费用与限额

| 项目 | 免费额度 | 说明 |
|------|---------|------|
| Cloudflare Workers | 10 万次请求/天 | 远超初期需求 |
| Cloudflare KV 写入 | 1000 次/天 | 每次深度请求计 1 次；命中缓存不计数 |
| DeepSeek API | 按量付费 | 你的唯一真实成本，单次翻译约几厘人民币 |

缓存：单词分析 30 天、句子解析 7 天，同一内容第二次查询不花钱、不扣用户次数。

## 安全红线

1. `cloud.json`（管理令牌）和 `keys.json`（DeepSeek Key）已 gitignore，**永不提交、不外发**
2. DeepSeek Key 只存在云端 KV，客户端永远接触不到
3. 管理接口 `/admin/*` 需要 ADMIN_TOKEN，普通请求打不进来
