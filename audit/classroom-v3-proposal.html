课堂 v3 · 主功能改版方案 · 先方案后实施

课堂 = 保存库 + 独立录制页

课堂标签页变成「我的课堂内容」主页：只留一个长条「➕ 新建翻译」入口，下方网格铺满已保存的正方形场次卡（日期 + 课程类型 + 长按调色）。录制（录音/停止/段卡/字幕/保存）整体搬进独立页面，保存按钮常驻。

基于 课堂 v2 已落地代码（32336c0）改版范围 index.html 课堂屏 + 新增 class-recorder.html
01

两个页面怎么分工

页面放什么不放什么
课堂主页
（原 sClass 屏）		① 顶部一个长条按钮「➕ 新建翻译」（点击跳录制页）② 下方两列正方形场次卡网格：日期、课程类型徽章、课程名、段数/句数，长按弹调色盘改卡色 ③ 点卡进详情（复用已做的 classOpenSessionDetail）开始/停止/保存录音按钮、字幕板、术语/校准/滚动——全部移走或搬到录制页
录制页
（新增 class-recorder.html）		完整录制工作台：开始/停止、字幕板、段卡（录音N + 复制原文/译文/试听/导出）、术语面板、静音校准、滚动开关、回放重翻；「💾 保存并结束」按钮固定常驻（录制中=保存并结束，未录制=返回主页）——

录制页用独立 HTML 而不是主应用内的隐藏屏：录制中锁屏/切后台回来状态不丢，代码隔离干净（主 index.html 只减不改），localStorage/appTheme/账号体系天然同源共享。

02

课堂主页：正方形卡网格

  • 布局：CSS Grid 两列，aspect-ratio:1 正方形卡，卡片内容三行——顶部日期（大字）、中部课程类型徽章（语法/听力…，取自卡色系统一渲染）、底部「N 段 · M 句」统计。新建的排最前。
  • 卡色：每张卡一个自定义底色（存 sessions.color，默认按课程类型自动分配——语法=蓝、听力=绿、口语=橙…），同类型课在列表里一眼可辨。
  • 长按调色：长按 350ms 触发（手机）+ 右键（桌面）；弹出居中调色面板：上方的圆形色盘（HSL 环，手指拖动取色相）+ 下方三条滑轨（色相 H / 饱和度 S / 明度 L，0–255 可滑动微调）+ 实时预览块 + 确认/取消。选色写入该卡的 color 字段，主页卡背景立即换色。
  • 保留操作：卡右上角 ⋯ 菜单：复制全文 / 导出 Markdown / 删除（删卡连段落音频一起删）。
03

录制页：流程与常驻保存

进入
主页点「➕ 新建翻译」→ 录制页顶部就是表单（日期/类型/课程名）→「开始录制」开麦。从主页某张卡的"继续上课"进入则跳过表单直接续录（同一场次追加段）。
录制中
字幕板 + 段卡照 v2 逻辑走：60 秒静音切分识别、300 秒出「录音N」、48 段上限自动收尾。
💾 保存（常驻）
固定在页面底部，任何状态可见可点：录制中=保存并结束（走完整收尾：尾段落库、批量翻译回填、录音落库）；已完成=返回主页；无内容=置灰。不再有"保存按钮随 5 分钟段消失"的问题。
保存后
自动跳回课堂主页，新卡出现在网格第一位，带刚选的卡色。

兼容与风险

① 录制中误触返回：录制页加 beforeunload 拦截 + 录制中底部按钮变「保存并结束」，避免误滑丢课。② 旧数据（无 color 字段）：按 ctype 映射默认色，不迁移。③ APK 端跳转：同源相对路径 file 链接在 Capacitor WebView 内直接可用，无需额外配置。④ 体验额度（15 段）与接入码逻辑不动。

工作量：主页改版 + 调色盘 ≈ 1 天；录制页搬迁 + 常驻保存 ≈ 1 天；联动测试 ≈ 半天。合计约 2.5 天，一个发版走完。
