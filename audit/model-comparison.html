04

决策建议

现在换吗？—— 不换。做两件低成本的事：

  • 翻译：维持 DeepSeek。等 5 分钟分段方案落地后按段批量翻译，成本再降一半，译文质量还会因为"整段上下文"更好。
  • 识别：排期 GigaAM v3 本机 PoC（半天）。下载 RNNT 版 → stt_server 加双模型开关 → 用你的真实课堂录音跑同段对比（WER 抽查 + 幻听率 + 速度）→ 数据说话：赢就上"本机高质量档"，输就继续 Whisper。
  • 商业 API 档：观察不动。触发条件只有两个——用户规模大到本机/CF 免费额度不够用，或出现"必须云端流式低延迟"的新需求；届时优先测国内可达的 GLM-ASR，而不是美国三家的中转。
